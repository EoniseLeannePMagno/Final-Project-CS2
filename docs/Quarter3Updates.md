Update:

The “search record” feature allows users to find a specific record stored in the firebase realtime database. As the user enters a name, the program retrieves all the stored records from the database and compares each records name to the provided input.  If a match is found, the program displays the complete information of that record. If no match is found, the system informs the user that the record does not exist. This feature will improve the efficiency of the system by allowing users to locate quickly a specific data, without manually checking the records.
